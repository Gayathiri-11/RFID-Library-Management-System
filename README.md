# RFID Library Management System

## Features

* RFID Based Book Management
* Add/Edit Books
* Add/Edit Students
* Issue Books
* Return Books
* Fine Calculation
* Reports Dashboard
* Excel Export
* RFID Replacement for Damaged Tags

## Technologies Used

* Python
* Flask
* MySQL
* HTML
* CSS
* RFID (MFRC522)

## Future Enhancements

* Smart Shelf Tracking
* Misplaced Book Detection
* IoT Integration
* AI Analytics
